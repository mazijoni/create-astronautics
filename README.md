# Create Astronautics

A space exploration addon for [Create](https://www.curseforge.com/minecraft/mc-mods/create), built on top of Create Aeronautics and Sable. The goal is to take the contraption-building of Create off the ground and out past the atmosphere: fly through the sky with Create Aeronautics, then push further into orbit, to the Moon, and beyond using rockets and spacecraft built from Create machinery.

## Vision

- **Rockets and spacecraft** assembled from Create contraptions, using Create Aeronautics engines/propulsion as a foundation for true orbital and interplanetary travel.
- **Multiple space bodies to explore** — the Moon and Deep Space today, with more planets and moons planned, each with their own terrain, hazards, and resources.
- **Survival in a vacuum** — no breathable air, low or zero gravity, and other hazards that demand proper suits and life support to survive.
- **Space suits and life support gear** that protect players and let them work safely off-world.
- **Resources unique to space** to fuel progression once you leave Earth, tying back into Create's automation and logistics.

## Requirements

- Minecraft 1.21.1
- [NeoForge](https://neoforged.net/) 21.1.244+

Create, Create Aeronautics, and Sable are supported as soft/optional dependencies for now — the current feature set (worldgen and dimensions) doesn't call into their code yet.
